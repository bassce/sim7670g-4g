# 车型 PID 模板

- `catalog.json`：模板目录，路径相对于本目录，SHA-256 对应多语言模板文件。
- `templates/`：服务器格式；同一份查询参数包含多语言 `description`。**不可直接导入当前固件。**
- `import/`：英文字符串 description 的兼容配置，可在现有 OBD States 页面导入；导入会替换状态列表，请先导出旧配置。

提供标准燃油车基础测试（转速、车速、冷却液温度）及本项目实测的 ID.4 四项基础数据。标准测试项仍取决于车辆支持，ID.4 模板不是通用电动车模板。测试模板不含清除故障码或写车辆配置指令。

`name` 是稳定的公式/MQTT 标识；仅 `description` 随语言变化，不新增说明字段。未来下载器选择当前语言（缺译回退英文），保存为设备已有的配置结构。语言切换只更新匹配模板的文案，不覆盖用户 PID、公式和启用状态。模板来源及版本用于匹配，不能仅凭相同 name 更新自定义条目。

当前提交只准备资源结构，网页在线下载、模板预览应用和语言切换尚未实现；现有 data/states.json 未替换。Gitea 可镜像整个仓库，实际文件直链需按部署地址配置，不能把仓库 HTML 页面作为 JSON 下载地址。
