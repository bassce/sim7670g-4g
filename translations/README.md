# Web 界面语言包

日本語 `ja.json`、简体中文 `zh-CN.json` 和英文兜底 `en.json` 各包含 273 条文案，语言包版本 `1.0.2`，适用于 `uiSchemaVersion: 1`。这不是固件版本号。

## 使用状态

需要已接入语言加载的固件，例如本机已安装的 `v1.0.0-resources.1`。本次仅更新在线资源，不发布尚待测试的固件和网页加载器源码。旧固件仅有语言文件时不会自动显示语言选择功能。

在“语言与模板”页面刷新在线目录，选择“日本語”，再点击“应用语言”。已缓存的语言可离线切换，点击“在线更新语言包”才主动重新下载。英文兜底在网页中，设备只保留一个外挂语言 JSON 和一个很小的语言选择文件。切到英文不会删除外挂缓存；切换另一种外挂语言会替换原外挂缓存。

覆盖导航、设备信息、设置、蓝牙连接、OBD 数据编辑、协议与数据类型选项、现有本地 OTA 上传页、参数校验及已定义的蓝牙错误码。翻译已有 OTA 页面不代表新增在线检测或升级功能。未知的浏览器、HTTP、底层库错误通过带 `{detail}` / `{code}` 的兜底文案显示原始信息，不能保证未知原文为中文。

## 文件

- `ja.json`：日语包，UTF-8、LF，无 BOM；不附带字体。
- `zh-CN.json`：简体中文包，UTF-8、LF，无 BOM。
- `en.json`：与中文完全相同的键，用作英文兜底。
- `*.json.gz`：相同 JSON 的 gzip 文件，供其他客户端使用；当前设备下载并缓存 JSON，不同时存两份。
- `catalog.json`：相对下载路径、文件大小和 SHA-256。gzip 与解压后 JSON 分别提供校验值。
- `messages.tsv`：文案编辑源，四列依次为稳定键、英文、简体中文、日语；服务器保留，设备无需下载。
- `build.py`：生成及校验工具；服务器/开发电脑使用，设备无需下载。

只将语言 JSON 作为数据解析和显示，不执行脚本，不把服务端文案直接作为 HTML 注入。链接和文件名仍由应用控制。新语言必须使用相同键并保留 `{name}`、`{code}`、`{detail}` 等占位符；语言切换时由加载器替换，不能直接交给 Angular 编译为模板。

## 术语与边界

- OBD 配置 `name` 的标签译为“固定标识”，实际字段值不翻译；`description` 的标签译为“显示名称”。
- 车型模板 description 的多语言值由 `pids/` 管理，语言包不覆盖用户自定义 PID 描述。
- 保持 PID、CAN 地址、MQTT 主题、公式变量、函数名和标准单位不变，只翻译显示标签。
- GPS、MQTT、ELM327、ISO、PIN、APN 等技术标识保留，必要时配中文解释。
- `Power` 为“功率”，`Energy` 为“电能”，不混用 kW 与 kWh。
- 休眠文案对应现有其他板型的设置，当前 SIM7670G 节电方案尚未实现。

## 维护和校验

在项目根目录使用 Python 3 运行 `python translations/build.py`。工具检查重复键、空译文、占位符一致性、静态 HTML、动态提示、枚举选项、已定义错误码，以及 gzip 往返；输出确定的 LF JSON 并更新目录校验值。

新增或修改界面时应同步更新文案，并同步生成 `ui/src/app/i18n/en.ts`。静态文案使用稳定键，兼容原有动态枚举的文本映射。例如设备信息的 `Name` 与 PID 编辑器的 `Name` 已按语境分别翻译。

GitHub 与 Gitee 镜像应同步整个 translations 目录。国内地址为 `https://raw.giteeusercontent.com/bassce/sim7670g-4g/raw/main/`，国际地址为 `https://raw.githubusercontent.com/bassce/sim7670g-4g/main/`；目录路径为 `translations/catalog.json`。自动模式优先国内源，失败后尝试 GitHub；也可固定选一个源。

下载经开发板移动网络，由 ESP32 校验 HTTPS 证书、主机名及证书日期；目录内资源再校验 SHA-256。文件上限 64 KiB。下载失败或格式不兼容保留原包，缺少键回退英文。同语言旧包更新时保留本地已有的额外文案，便于新固件配合尚未同步的镜像测试。切换语言不会改写用户的 PID 配置、公式或 MQTT 标识。

日语 JSON 约 19.2 KiB，gzip 约 6.0 KiB。两份在线车辆模板已添加日语 `description`，并提供 `.ja.json` 兼容导入文件；固定标识、地址、服务码、PID、公式和单位保持不变。已烧录的离线内置模板不会随在线目录自动更新，日语显示名称请使用在线下载的模板。国内镜像同步前可临时选择 GitHub 下载源。
